?How to use
  1. Fill or edit the shaded fields directly on the marksheet (or click Import Excel to load students from your .xlsx file). Click the logo to change it.
  2. Shortcut: type AA for A+ and BB for B+ (works in the Excel file too).
  3. Enter only the FA1 and SA1 grades (and ART). TERM 1 = average of FA1 and SA1, TOTAL = average of the three TERM 1 grades, Overall Grade = average of all subject totals; an exact half goes to the lower grade. Untick Auto-calculate to type them yourself.
  4. Before saving, every field is checked: all student details and grades must be filled, the Admission No. must be unique, and the Roll No. must be unique within the same Class / Section. Problems are shown in a red message and the fields turn red.
  5. Click Generate & Save PDF. The first time, pick a folder (for example Documents) — a Marksheets folder is created inside it and every PDF is saved as Marksheets/<Admission No>/<Admission No>.pdf. Later saves go there automatically.
  6. Save All PDFs does every student in one go — as separate PDFs in one folder, or as one combined PDF (one student per page). Print opens the print dialog with only the A4 marksheet.
  7. Tap Generate & Save PDF and confirm the download — the file is named <Admission No>.pdf. Save All PDFs gives either one combined PDF (one student per page) or a ZIP with all PDFs in one Marksheets folder. On iPhone, choose Save to Files.
Everything you type is kept in this browser automatically. Automatic folder saving needs Google Chrome or Microsoft Edge on a computer; in other browsers the PDF downloads as <Admission No>.pdf and "Save All" downloads a ZIP with the same folder structure.
